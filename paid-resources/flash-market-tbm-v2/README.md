# Flash Market (TBM) v2

## Flash Trade & Buy Market - TBM v2

This script provides a complete marketplace system for FiveM servers, allowing players to trade items and vehicles securely. It includes logging, search functionality, listing management, and multi-currency support. The script works with <mark style="background-color:blue;">**ESX**</mark>**,&#x20;**<mark style="background-color:blue;">**QBX**</mark>**, and&#x20;**<mark style="background-color:blue;">**QB-Core**</mark> frameworks and also supports <mark style="background-color:blue;">ox\_inventory</mark> and <mark style="background-color:blue;">qs-inventory</mark> inventories
