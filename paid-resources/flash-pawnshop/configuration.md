# Pawnshop Configuration Guide

This guide provides a comprehensive overview of the configuration options for the Pawnshop resource. The configuration allows you to customize various aspects of the pawnshop system to suit your server's needs.

## Configuration Files

- `shared/config.lua`: The main configuration file containing all customizable settings
- `fxmanifest.lua`: Resource manifest file
- Inventory-specific configuration files
